A language model that is not a transformer, and has no tokenizer.

Braid reads and writes raw bytes. Most layers are cheap gated causal convolutions doing local work; the sequence is folded down by 16× through a causal U-Net so that full attention runs only where the sequence is short, and one sliding-window attention block on the way back up covers the recent bytes the coarse path cannot see. An exact suffix-copy branch handles literal repetition beside the neural head.

The result is a model that trains and runs cheaply for its size. It is not a frontier model, it is not instruction-tuned, and on equal-data quality a matched dense transformer still wins by a small margin. See the benchmarks for the measured numbers.

Limitations

  • Research preview. Output is frequently wrong, repetitive, or nonsense.
  • No instruction tuning, no alignment, no safety filtering, no retrieval.
  • Byte-level: it can emit invalid UTF-8, which is rendered as �.
  • Bounded coarse attention: this is not a long-context model.
  • Do not use it for facts, code you will run, or anything with a cost.
